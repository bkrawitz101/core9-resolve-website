Newsletter setup rules

  • Use only opted-in subscribers, lawful sender identity, postal address and unsubscribe link.
  • Avoid duplicate sends if episode is rescheduled; ensure scheduled send occurs only after page and audio are live.
  • Use separate UTM values for show, episode and campaign; track clicks to page and booking, not merely email opens.
  • Test links, subject, mobile rendering and unsubscribe in a seed list before launch.
  • Never assume a newsletter platform is already connected; obtain access from owner.
